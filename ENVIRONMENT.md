# Environment contract

`DATABASE_URL`, `AUTH_SECRET` (minimum 32 random characters) and `DEFAULT_TENANT_ID` are required. Production also requires `OIDC_ISSUER`, `OIDC_CLIENT_ID`, `OIDC_TENANT_CLAIM`, and `OIDC_ROLE_MAP_JSON`; `OIDC_CLIENT_SECRET` is required for confidential clients. The authorization-code flow uses discovery, PKCE, state, nonce, issuer/audience checks, and remote JWKS verification. The mapped tenant claim is embedded in the signed session and used by governed queries. Local password login is disabled in production. Optional `OIDC_REDIRECT_URI`, `OIDC_ROLE_CLAIM`, `OIDC_SCOPES`, and `PORT` (default 5311) are documented in `.env.example`. Keep values in a secret manager and never commit credentials. `ALLOW_SCHEMA_MIGRATION=1` is a one-command authorization flag, not a stored setting.
